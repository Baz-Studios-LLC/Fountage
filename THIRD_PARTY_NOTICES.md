# Third-party components

Fountage uses Slint and other Rust dependencies. Release archives include dependency metadata and available upstream license/notice texts in THIRD-PARTY-LICENSES. The dependency inventory includes build and platform dependencies as well as runtime components.

Slint is copyright its respective authors. Its upstream licensing notices are preserved under prototypes/slint/vendor/i-slint-core/LICENSES. The application provides the AboutSlint widget through Help → About Slint. Fountage's pinned extensions are described in that package's FOUNTAGE_PATCH.md; these extensions are not upstream Slint APIs.
